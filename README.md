
# 🛒 Sistema de Simulación de Cola de Supermercado - Equipo 2

![Logo](https://img.freepik.com/vector-premium/concepto-cola-supermercado_118813-1050.jpg)

Simulador de colas basado en el modelo M/M/c (Colas Markovianas con c servidores). Evalúa escenarios realistas considerando:

- Llegadas de clientes aleatorias (Distribución Poisson) ⏲

- Tiempos de servicio exponenciales 📃

- Variabilidad en el número de cajeros 🧑‍💻

## 🛠️ Instalación local
 1. Clonar repositorio
 ```
 git clone https://github.com/Jeremyurbina/supermercado-cola/tree/gui-streamlit)
 ```
2. Crea un entorno virtual.
```bash
python -m venv venv
#Windows:
venv/Scripts/activate
#Linux
source venv/bin/activate
```
3. Instalar las dependencias
```bash
pip install -r requirements.txt
```
## ⚡ Ejecución del proyecto
Ejecutar el servidor 🚀 :
```bash
streamlit run app.py
```
se abrirá automáticamente en: 
```bash
`localhost:8501`
```
